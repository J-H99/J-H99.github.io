## 제작 방식

본 프로젝트는 직접 코드를 작성하거나 코드 품질을 라인 단위로 수동 검토하지 않고, ChatGPT Pro의 Codex 세션을 통해 요구사항 정의, 구현, 수정, 검증을 진행해 제작했습니다.

## Sections

- `notes/`: 새로 공부한 내용을 글로 정리합니다.
